暗号化ボルト

ファイルやメモを age 形式で暗号化・復号します。パスフレーズ式と鍵ペア式の両方に対応し、 処理はすべて端末内で完結します。生成した暗号文は age CLI や sops と同じ形式です。

暗号化

パスフレーズは scrypt で鍵に変換されます。忘れると復号できないため、必ず別の場所に控えてください。

暗号化ボルトについて

ファイルやメモを age 形式で暗号化・復号します。age は age-encryption.org で仕様が公開されているモダンなファイル暗号化形式で、CLI の age や sops と同じ暗号文を扱えます。 処理はすべてブラウザ内で完結し、入力がサーバーへ送信されることはありません。

2 つの方式

  • パスフレーズ式: 覚えやすい合言葉だけで暗号化・復号します。手軽ですが、合言葉の強さがそのまま安全性になります。
  • 鍵ペア式: 公開鍵（recipient）で暗号化し、秘密鍵（identity）で復号します。秘密鍵を渡さずに相手へ暗号文を送れます。

使い方

  1. 「暗号化する」で方式を選び、テキストかファイルを入力します。
  2. 「ASCII armor」を有効にすると、コピーできるテキストとして出力されます。
  3. 「復号する」で暗号文と鍵を入力すると、元の内容に戻ります。

鍵ペアを使うときの注意

  • identity（秘密鍵）は復号に必須です。画面を閉じると再表示できないため、必ずダウンロードして保管してください。
  • identity は localStorage などに自動保存しません。共有端末では使用後に消去してください。
  • recipient（公開鍵）は相手に渡して構いません。identity は絶対に渡さないでください。

しくみ

  1. age-encryption（BSD-3-Clause, v0.3.1）を同梱し、ブラウザ内で実行します。
  2. パスフレーズは scrypt、鍵ペアは X25519 で鍵を導出します。
  3. 出力は標準 age 形式なので、CLI の age -d でも復号できます。
