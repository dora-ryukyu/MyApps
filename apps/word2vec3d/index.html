カテゴリ

このアプリについて

2つのモード

ローカルモード (Ruri v3 130M)
名古屋大学が開発した日本語文埋め込みモデル。すべての処理がブラウザ内で完結し、テキストを768次元ベクトルに変換します。初回のみモデル（約127MB）のダウンロードが必要です。

Geminiモード (gemini-embedding-2)
Google の最新マルチモーダル埋め込みモデル。テキスト・画像・PDFを同一のベクトル空間にマッピングし、メディアを跨いだ意味の近さを可視化できます。APIキーが必要です。

仕組み

  1. ベクトル化 — 各入力をAIモデルに通し、768次元のベクトルに変換
  2. 次元削減（PCA） — 主成分分析で768次元→3次元に圧縮
  3. 3D可視化 — Three.js で3D空間にプロット。意味が近いアイテムは空間内で近くに配置される

読み方

空間内で近いアイテムは意味が似ていることを表します。「かわいい」というテキストと可愛い画像が近くに並ぶなど、モダリティを超えた関連性が見えます。

技術スタック

ローカル推論: Transformers.js（ONNX Runtime Web）
クラウド推論: Gemini Embedding API
描画: Three.js
