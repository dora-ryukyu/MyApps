日本語アシスタントについて

端末内の日本語 LLM で、貼り付けた文章の要約・Q&A・構造化抽出を行います。 モデルのダウンロードと推論はすべてブラウザ内で完結し、テキストがサーバーへ送信されることはありません。

3 つのタスク

  • 要約 — 長い文章を 3〜5 文の日本語にまとめます。
  • Q&A — 文章についての質問に、文章中の情報だけから答えます。
  • 構造化抽出 — 指定した項目を抜き出して JSON で返します。

モデルとライセンス

LFM2.5-1.2B-JP（LFM Open License 1.0 / 非 OSI）。 日本語と英語に対応し、32,768 token のコンテキストを持ちます。研究・個人利用の範囲でお使いください。

しくみ

  1. WebGPU が使えれば q4f16 の重みで実行し、無ければ WASM + q4 に自動フォールバック
  2. 生成はトークン単位でストリーミング表示
  3. モデルは Cache Storage（transformers-cache）に保存され、2 回目以降は再ダウンロードされません
