テキスト→画像生成について

プロンプトから 512×512 の画像を生成します。モデルのダウンロードと推論はすべてブラウザ内で行われ、 プロンプト・生成画像がサーバーへ送信されることはありません。

使用モデル

utkucoban/NanoDiffuser — Stable Diffusion XS を one-step 用に量子化した 約 382 MiB のモデル。CLIP テキストエンコーダ + U-Net + TAESD デコーダを ONNX Runtime Web の WebGPU で実行します。

しくみ

  1. プロンプトを CLIP トークナイザーで 77 トークンに変換
  2. シードからガウスノイズを生成
  3. one-step U-Net でノイズを除去（拡散ステップは 1 回）
  4. TAESD で 512×512 の RGB 画像にデコード

保存とプライバシー

モデルはブラウザの Cache Storage に保存され、2 回目以降は再ダウンロードされません。 生成画像は端末内の Canvas にのみ存在し、明示的にダウンロードしない限り保存されません。
