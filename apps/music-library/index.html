    音楽ライブラリについて

    手元の音源フォルダをその場で読み取り、タグを一覧・検索・編集できるようにします。音源もタグも サーバーへは送信されません。解析ライブラリ（music-metadata）と ID3 書き込み（browser-id3-writer） だけを CDN から読み込みます。

    使い方

    1. 「フォルダを選ぶ」で音源フォルダを選ぶと、再帰的に走査してタグを読み取ります。
    2. 一覧の行を選ぶと右側でタグを編集できます。「変更を反映」で一覧に反映、「タグを保存」でファイルに書き込みます（MP3 のみ）。
    3. プレイリストに曲を追加し、M3U / M3U8 で書き出せます。

    できること / できないこと

    • タグの書き込みは MP3（ID3v2.3）のみ。FLAC / Ogg / MP4 などは読み取り専用です。
    • フォルダ選択（File System Access API）は Chromium 系のみ。Firefox ではファイル選択 + ダウンロードになります。
    • タグを含むライブラリ情報は IndexedDB に保存します。次回起動時はファイルを選び直すと再生できます。
