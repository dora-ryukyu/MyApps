      RSS リーダーについて

      RSS / Atom フィードを購読し、記事の本文だけを抽出して読むためのローカルアプリです。 購読リスト・既読・あとで読むは localStorage に保存され、サーバーへは送信しません。

      使い方

      1. フィードまたはサイトの URL を入力して「購読」を押します (サイト URL ならフィードを自動検出します)。
      2. 「全て更新」で新着を取得し、記事を選ぶと本文ビューが開きます。
      3. 「Markdown」で本文を Markdown 表示し、「.md 保存」または「notes-vault へ」で手元に残せます。
      4. OPML の取り込み / 書き出しで購読リストを移行できます。

      注意

      • 配信側が CORS を許可していないフィードは取得できません。その場合はエラーとして表示します (プロキシは使いません)。
      • 本文抽出は @mozilla/readability、Markdown 化は turndown を使い、読み込めない場合は内蔵の簡易抽出にフォールバックします。
      • 読み込み済みライブラリ: jsdelivr の版固定 CDN のみ。記事の内容はどこにも送信しません。
