LLM Token Visualizer について

このツールは、AI（大規模言語モデル）が文章を生成する仕組みを、スポーツ実況のようにリアルタイムで観察・介入できる教育用アプリです。

⚙️ 使用モデル

LiquidAI / LFM2.5-1.2B-JP
1.2Bパラメータの軽量かつ高性能な日本語対応ハイブリッドモデル（LFM）です。WebGPUを利用して、あなたのブラウザ上で完全にローカルで動作しています。

🔍 ツールの見方

  • トークン境界: AIにとって言葉は「意味」ではなく「トークン（記号の破片）」です。出力のブロック分けを見ると、AIがどこで言葉を区切っているかが分かります。
  • 確率ツリー: AIの脳内で計算された「次に来る確率が高い言葉トップK」です。AIは常にこの確率に基づいてサイコロを振っています（自己回帰モデル）。
  • ハルシネーションの実験: 「手動選択」モードにして、あえて確率の低い変な言葉を選んでみてください。AIがその無理な文脈に合わせて嘘をつき始める（ハルシネーション）様子が観察できます！
