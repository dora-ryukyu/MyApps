スペクトログラムについて

音声を短い区間に切り出して周波数成分へ分解し、時間 × 周波数 × 強さの 2 次元画像として表示します。 帯域バランス、ノイズ、ハイハットやベースの成分など、耳では分かりにくい違いを目で確認できます。

使い方

  1. 音声を選ぶかマイクで録音します。
  2. FFT サイズ・hop・窓関数を決めて「解析する」を押します。
  3. スペクトログラム上をクリックすると、その時刻の周波数断面とピークが表示されます。
  4. 表示レンジやカラーマップを変えて見やすくし、PNG / CSV に書き出します。

パラメータの目安

  • FFT サイズを大きくすると周波数の分離が細かくなりますが、時間の分解は粗くなります。
  • hop を小さくすると時間方向が滑らかになりますが、計算量が増えます。
  • 窓関数は Hann が無難です。矩形は測定向きですがスペクトル漏れが増えます。

しくみ

  1. 音声をデコードし、モノラルへ変換
  2. Web Worker で STFT（窓掛け → FFT → 振幅 → dB）を実行
  3. dB 行列をカラーマップで Canvas に描画。断面・ピーク・CSV を生成

解析はすべてブラウザ内で完結し、音声がサーバーへ送信されることはありません。
