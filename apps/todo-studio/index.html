    使い方
    • 追加: 「＋ 新しいタスク」から、タイトル・期限・優先度・タグ・プロジェクトを指定します。
    • 完了: チェックを入れると完了。繰り返しタスクは次回の期限に進んで残ります。
    • ビュー: 今日 / 今週 / 期限切れ / すべて / 完了。タグ・プロジェクト・検索で絞り込めます。
    • ICS: .ics ファイル・貼り付け・購読 URL から VTODO / VEVENT (Moodle の締切) を取り込み、VTODO として書き出せます。
    • 今日をコピー: 今日と期限切れのタスクを 1 行にまとめてコピーします (Discord に貼る / /remind の入力に)。
    • すべてブラウザ内で完結し、タスクは送信しません。
