About This App

Models

高速（350M） — LFM2-350M-ENJP-MT。日英翻訳に特化した軽量モデル。
高品質（1.2B） — LFM2.5-1.2B-JP。日本語と英語に対応した汎用モデルで、 文脈を踏まえた訳になる代わりに、ダウンロードと推論が重くなります。 どちらも Liquid AI の LFM2 系で、Attention と Convolution を組み合わせた ハイブリッドアーキテクチャです。

Privacy & Security

  • 完全ローカル実行 — 入力データが外部サーバーに送信されることはありません。
  • オフライン対応 — 一度モデルをダウンロードすれば、ネット環境がなくても動作します。

Real-time Mode

WebGPU のパワーを活用し、文字入力と同時に推論を行うリアルタイム翻訳を実現します。

Tech Stack

Inference: Transformers.js v4 (ONNX Runtime Web)
Models: LFM2-350M-ENJP-MT-ONNX / LFM2.5-1.2B-JP-202606-ONNX
Backend: WebGPU (Fallback to WASM/CPU)
