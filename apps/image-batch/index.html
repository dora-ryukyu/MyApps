    画像一括変換について

    たくさんの写真をまとめて「縮小して形式を揃えて軽くする」ためのツールです。 読み込んだ画像・透かし・出力はすべてブラウザ内で処理され、サーバーへ送信されません。

    できること

    • 長辺 / 短辺 / % での一括リサイズ（拡大はしません）
    • JPEG / WebP / AVIF / PNG への一括形式変換と品質調整
    • テキストまたは画像の透かし（位置・サイズ・不透明度・回転）
    • EXIF / 位置情報などのメタデータ削除
    • 連番リネーム（接頭辞 + 開始番号 + ゼロ埋め）と名前の衝突回避
    • 結果を ZIP で一括ダウンロード（1 枚だけならそのまま）

    しくみ

    1. 選択した画像を 1 枚ずつ Web Worker へ渡し、createImageBitmap でデコード
    2. OffscreenCanvas に描画してリサイズ・透かしを適用
    3. 指定形式へエンコード（非対応形式は自動でフォールバック）
    4. JSZip でまとめて ZIP にし、ブラウザからダウンロード

    注意

    • AVIF / WebP のエンコードはブラウザ依存です。非対応の環境では JPEG などへ自動で切り替わります。
    • GIF / BMP などは「元の形式を保つ」を選んでも PNG へ変換されます（静止画として読み込みます）。
