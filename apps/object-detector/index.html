物体検出について

画像の中にある物体を見つけ、ラベル・確信度・矩形（バウンディングボックス）を返します。 モデルのダウンロードと推論はすべてブラウザ内で行われ、画像がサーバーへ送信されることはありません。

使用モデル

  • D-FINE nano（COCO）（Apache-2.0）— リアルタイム DETR 系の軽量物体検出。COCO の 80 クラス（人・乗り物・動物・家具・食べ物など）。

しくみ

  1. 画像をデコードし、ブラウザ内でモデルに渡す
  2. 物体ごとのクラス・確信度・矩形を取得する
  3. しきい値で絞り込み、クラスごとの NMS で重複を除去する
  4. WebGPU が使えれば WebGPU で、無ければ WASM に自動フォールバック
  5. 検出矩形から切り出し・ぼかし（伏せ字）を行う

できないこと

COCO の 80 クラスのみが対象です。顔・ナンバープレート・日本語テキストなどは検出できません。 文字の読み取りは OCR 系、画像全体の説明は VLM 系のアプリが担当します。

保存とプライバシー

モデルはブラウザの Cache Storage（transformers-cache）に保存され、 2 回目以降は再ダウンロードされません。画像は端末内でのみ処理されます。
