音声文字起こしについて

音声ファイルを文字起こし、または対応言語へ翻訳します。モデルのダウンロードと推論はすべて ブラウザ内で行われ、音声・結果がサーバーへ送信されることはありません。

使用モデル

ibm-granite/granite-speech-4.1-2b（Apache 2.0）の ONNX 版。 Granite Speech 4.1 2B は英語・フランス語・ドイツ語・スペイン語・ポルトガル語・日本語の 音声認識と音声翻訳に対応します。ONNX Runtime Web の WebGPU で実行します。

しくみ

  1. 音声を 16kHz モノラルに変換
  2. 無音区間で分割（オプション）
  3. 音声エンコーダ + デコーダでトークンを生成
  4. 生成トークンをリアルタイムにテキスト化

保存とプライバシー

モデルはブラウザの Cache Storage に保存され、2 回目以降は再ダウンロードされません。 音声は端末内でのみ処理されます。
